# Dev. 角色制作队列

> 由于制作角色的流程极度复杂（见其他开发文档），且当前开发组制作速度不足以支撑当前的角色制作，所以，角色制作采用排队模式，请各位成员谅解。
>
> 本文档由Skyc8266管理，并依据文档分配角色制作工作任务

## 队列规则

- 角色制作队列分为三个优先级，第一优先级每人仅可上报一个，第二优先级每人至多2个，第三优先级每人至多3个
- 角色制作顺序按照优先级队列分配，每轮先进行第一优先级，随后是第二优先级，两个队列完成后进入下一轮填报与制作
- 第三优先级队列始终以缓慢速度进行制作，且总角色组数不超过15组，先到先得
- 第一优先级队列总角色组数不超过6组，先到先得
- 第二优先级队列总角色组数不超过10组，先到先得
- 如果提交制作该角色的人自己都没搞明白其人设与世界观（或者角色本身人设和世界观就极度模糊的），那么，无论提交到哪个队列，该角色都会被直接下降到第三队列，情况严重的将不予制作。
- 如果角色内容令人不适，则组内投票决定是否制作（情况严重的直接不予制作，无需投票）
- **若提交制作涉及违法的内容，则直接清除有关数据。首次警告加禁止提交资产制作至少275天，第二次再犯，直接从隙间开发组永久移除提交者。十分严重的，直接移出开发者、并将证据等信息上报公安**

## 角色制作速度

- 对于世界观复杂的角色（例如鸣潮中的今汐、陆赫斯等），从零开始制作预计25～32天
- 对于世界观较为简单的角色（例如千恋万花中的芳乃），从零开始制作，预计5～14天
- 通常为4组角色同时制作

## 提交制作角色

> 这是一个模板，请您在提交时通过QQ、钉钉、Github、Bilibili或电子邮件联系管理员（Skyc8266），管理员会为您安排制作
>
> 当前仅开发组成员允许提交
>
> 请将模板中的“<>”标签替换为您自己的内容

```plaintext
[隙间项目角色制作提交]
角色名：<角色名字，例如“弗洛洛”>
性别：<性别，例如“女”，不要填奇怪的东西>
生日：<生日，尽量写上年份，优先用标准日期，若使用游戏内的时间系统，请务必注明，标准格式为YYYY/MM/DD，如2012/09/10>
来源：<角色来源，哪个作品中的，例如“鸣潮”，“崩坏：星穹铁道”，写全名！在名字后面附上其官网链接，不接受任何付费的作品，如果是付费的，请提供有效授权，否则退回，不予制作；注：F2P 类游戏中需要通过抽卡获取的角色不属于付费内容>
简介：<一段简单的介绍，稍微详细点，80～200字之间>
制作备注：<特殊说明（可以不写）。例如“请在模型中添加一个墨镜”>
制作资产说明：<指定在角色制作中你想使用的资产，仅接受开源、免费且允许商用的，务必写明作者！格式为：1. 模型；https://example.com/models/amodel.zip；一个普通的作者；MIT License>
目标提交队列：<提交到哪个队列，只写阿拉伯数字，支持1、2、3，不写就是3，第1第2先到先得，没名额了会通知你，并且暂时转移到第3队列>
```
