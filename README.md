## 功能介绍

**注意**：如果要获取详细的功能清单，请查看"docs/Dev. Function List功能清单v2.md"

1. **实时对话**：与角色进行实时语音对话，角色还会通过其3D模型做出回应，增强互动能力
2. **模拟世界**：在与角色的各类互动中可能会遇到各种突发事件，用户还可以通过UI按钮，选择不同交通方式前往不同场景（地点），**系统自带**有经济、健康、饮食、体力、心智等角色状态系统，您可以更好的进行互动。
3. **互动系统**：各种各样的互动可以让您与角色增进感情，（**注意**：包含**NSFW**内容的互动默认被隐藏）角色可以拒绝或同意，在互动期间，角色会做出各种回应，使互动更加真实，增强用户体验。
4. **主动聊天**：角色可以向用户主动发送消息！用户可以把角色放在系统壁纸中，重点是！壁纸中的角色可以正常做出回应、进行互动，就像在App中那样！（该功能需保持主程序开启，且设备性能支持本程序在后台进行活动）当然，您也可以选择将角色作为桌宠，如果您同意，他还可以看到电脑屏幕，甚至操控你的电脑！（该功能需保持主程序开启，程序将提供应急快捷键，用于紧急中断Ai操作，防止不必要的损失，但本应用开发组不为因使用本应用造成的任何损失承担责任）
5. **长期记忆**：你与ta的每一次互动、对话都会被记住，一部分会成为长期记忆，一部分则会被渐渐遗忘。但是！用户可以手动管理记忆，自主添加、删改记忆，并设置属性。
6. **自主保护**：这是核心模块之一。程序会通过多种方式，防止绝大多数提示词注入，同时防止ai出现OOC等情况。ai数据的每次变更都会被保护模块记录，如果出现异常，用户可以要求保护模块回滚到以前的数据版本。当然，如果您必须要关闭保护系统，但是需要双重确认，以防止误操作带来的损失。当系统过载时，保护模块也会强制终止Ai模块与相关进程。

## 设备支持

**操作系统与版本**：
- macOS >= 26.0（原生 macOS 应用，SwiftUI）
- Windows >= 10 22H2 / 11（建议 24H2 及以上，Core API 支持）
- iOS / Android：**仅作为连接电脑的伴侣端**，需连接运行隙间最新版本的 macOS/Windows 计算机，无原生客户端

**最低配置**：

- **macOS**：M 系列芯片必需，16 GB 内存（可用 ≥ 6 GB），硬盘可用空间 ≥ 24 GB
- **Windows**：显存 ≥ 20 GB（建议更高），SSD 硬盘，可用空间 ≥ 26 GB

**说明**：本程序在本地运行 Ai，故对设备配置要求较高。Windows 要求略高于 macOS，是因为 Core API 与 UI App 在两平台的实现逻辑与框架不同。iOS/Android 当前无原生客户端，仅作为连接电脑的伴侣端使用。

## 项目特点介绍

### 本地Ai

您与角色互动时，数据将始终保持在本地，因为我们默认**在本地运行Ai**。所以，这将对设备配置有较高要求。

**解释**：我们没有钱去购买云端Ai服务为用户提供支持，也不希望用户的数据被上传到云端，所以决定在本地运行全部Ai。
但是，有些用户的设备配置明显是不足以本地运行Ai的，因此，我们也允许用户连接到OpenAi兼容的Api服务，
来正常体验Ai功能

### 真实的互动

本项目在设计之初就是为了更真实的互动。为了这一点，我们添加了记忆系统、模拟世界以及其他多个模块，
希望这能为大家带来更好的体验，希望大家能够向我们发送使用反馈，以便我们优化项目功能。

## ⚠️ DevKit 自动更新安全声明

**DevKit 创作者工具内置自动更新功能（基于 GitHub Releases），请务必阅读以下安全声明：**

- **故意禁用 TLS 证书验证**：由于中国大陆用户必须通过代理/加速器访问 GitHub，代理的 TLS 拦截会导致证书验证失败。为保证更新检查/下载基本可用，更新器在所有网络请求中禁用 TLS 验证（`ssl.CERT_NONE`）。
- **无代码签名 / 无校验和验证**：本项目为完全开源免费软件，开发组不持有、也不打算获取代码签名证书。因此无法提供代码签名验证（Apple notarization、Windows Authenticode、Linux GPG 等）。考虑到分发渠道不可控、GitHub Releases 自身可能被篡改、无签名基础设施下 SHA 校验和只能提供虚假安全感，**故意不实现**下载后的校验和/签名验证。
- **风险自担**：更新检查/下载流程**不提供传输层机密性/完整性保证**。任何能劫持到 GitHub 连接的攻击者（代理运营商、ISP、DNS 劫持者等）均可注入任意更新包，导致以当前用户权限执行恶意代码。**使用自动更新功能即表示您知晓并接受上述风险**。如需更高安全性，建议手动从 GitHub Releases 下载并自行验证，或使用操作系统包管理器分发。
